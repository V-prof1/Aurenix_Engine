# Neon Rift — teste oficial da Aurenix Engine
Minijogo editável nativo **Aurenix** (Scripts / 2D top-down), não é uma importação HTML5.

## Como jogar
Use o analógico do Android ou WASD/setas do computador para andar. Toque A (Espaço) para escudo temporário, B (F) para turbo. Pegue cinco fragmentos, fuja dos inimigos e entre no portal liberado à direita. Três arenas + cena de vitória.

## Abrir e editar dentro da Aurenix
1. Abra o editor Aurenix Engine (Alpha 0.10).
2. Use **Importar projeto** e selecione **neon-rift.aurenix.json**.
3. Toque **▶ Testar**. Edite e salve o projeto como desejar.

## Recursos exercitados
Cenas, transição via API, tilemap 2D, paredes sólidas, animação por keyframes, componentes (colecionável, partículas, dano, perseguição, patrulha, checkpoint), HUD, saúde/respawn, controles por toque, scripts, som sintético e FPS.

## Preview online
Abra o index.html desta pasta pelo GitHub Pages (deve estar publicado no ramo main); ele usa o **mesmo runtime** do editor e carrega o JSON. Para jogar offline, importe o JSON diretamente no aplicativo.

Este teste foi criado como um exemplo independente; nenhum arquivo do editor foi substituído.
